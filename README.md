# 📅 Calendar Availability Finder

> מערכת לניתוח יומנים ואיתור חלונות זמן משותפים לפגישה בין מספר משתתפים.

הפרויקט טוען נתוני פגישות ממקור CSV, מעבד אותם לוגית, ומחזיר רשימה של חלונות זמן שבהם כל המשתתפים הנדרשים פנויים — תוך התאמה לאורך הפגישה המבוקש ולגבולות יום העבודה.

---

## 🛠️ יכולות המערכת

- **קריאת קבצי CSV** — טעינה ועיבוד נתונים גולמיים לאובייקטי `Meeting` מובנים.
- **אלגוריתם מיזוג זמנים** — איחוד פגישות חופפות של מספר אנשים ל"בלוקים" רציפים של זמן תפוס.
- **מציאת חלונות פנויים** — חישוב זמני התחלה וסיום אפשריים בהתבסס על משך הפגישה המבוקש (`Duration`) ובגבולות יום מוגדרים (07:00–19:00).
- **דיוק בחישובי זמן** — פתרון בעיית סנכרון תאריכים על-ידי איחוד כל אובייקטי ה-`datetime` לציר זמן אחיד.

## 🚀 הוראות הרצה

### דרישות קדם

- Python `3.12` ומעלה
- ספריית `pytest` להרצת הבדיקות
```bash
pip install pytest
```

### הרצת התוכנית
```bash
python -m io_comp.app
```

### הרצת בדיקות יחידה
```bash
pytest
```

| שם הבדיקה | תיאור |

| `test_no_slots_available` | פגישה ארוכה שחוסמת את רוב היום — אין חלון פנוי |
| `test_merged_overlap` | שתי פגישות חופפות של שני אנשים — מאוחדות לחסימה אחת |
